# CLAUDE.md

Guidance for Claude when working in this repository.

## Building

The APK the user installs comes from GitHub Actions: every push runs
`.github/workflows/build.yml`, which runs the unit tests, builds the release
APK and publishes it as a GitHub release (and an artifact). After pushing,
check that workflow run and fix it if it's red.

Building locally to check a change before pushing is fine
(`./gradlew testDebugUnitTest assembleRelease`, JDK 21 + Android SDK), but
never ask the user to build or install anything by hand.

`AppTest` drives every screen under Robolectric and writes PNGs to
`app/build/screenshots/`. Look at them after UI changes.

## Plan data

`app/src/main/assets/` is generated by `tools/import_streek.py` from the
sibling `streek` repo. Don't hand-edit it; change the script or streek and
re-run it. The streek data is paid content, so this repo stays private.
